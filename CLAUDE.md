# Alero · demo de inmobiliaria (paquete Básico)

Marca ficticia: inmobiliaria con buscador de propiedades, fichas en ventana (hoja deslizable en celular)
y calculadora de crédito. Ficha completa de diseño: `docs/alero.md`.

- Sitio: https://demo-inmo-alero.vercel.app (Vercel `demo-inmo-alero`). Repo `BrunoDunay/Demos-de-inmoviliaria`: push a `main` publica.
- Código: workspace de Angular 22 en `frontend/` con la app `projects/inmo-alero`. Estático prerenderizado, CSS + IntersectionObserver.
- Comandos (desde `frontend/`): `npm start`, `npm run build` (sale en `dist/inmo-alero/browser`).
